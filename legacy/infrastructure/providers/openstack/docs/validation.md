# 초기 구현 검증 기록

검증일은 2026-10-01이며, 결과는 dev 디렉토리의 초기 구현에 대한 기록입니다. 실제 OpenStack에 접속하거나 자원을 변경하지 않았습니다.

pytest의 최종 결과는 243 passed, 51 warnings입니다. 경고는 Starlette TestClient의 HTTPX 사용 중단 예정 안내1개와 OpenStack SDK 내부의 SDK5.0 제거 예정 메서드 안내50개입니다. 실패로 처리하지 않았고 경고를 숨기지 않았습니다. 향후 의존성 갱신 시 재검증해야 합니다.

## 시험 내용

- 단일 생성 및3개 생성 요청 취합, 목록 페이지 경계, 상세 조회, 정지·시작·일반 재부팅, 삭제 후404 및 재삭제204
- 인증 실패가 JSON 파싱보다 우선하며 공급자를 호출하지 않는지 확인
- 프로젝트·연결 대상 제한, 생성 참조 검증 순서, 잘못된 입력이 실제 생성으로 넘어가지 않는지 확인
- 외부 시간 초과의 결과 불명확 표시, 자동 재시도 방지, 비밀 값이 응답과 로그에 드러나지 않는지 확인
- 실제 SDK의 자원 객체·Compute Proxy를 사용하고 HTTP 경계만 대체하여 생성 본문·조회 쿼리·전원 작업 변환 확인
- 명시적 Keystone 인증, TLS 인증서 확인, 변경 요청의 재전송·리디렉션 차단, 정리 중 예외에도 연결 풀 해제 확인
- 계층 의존 방향 및 서비스와 공급자 규약의 시그니처 일치 확인
- 개발용 OpenAPI의 Bearer 인증 선언과 공통 오류 모델 확인

로컬 HTTP 시험의 공급자는 메모리 기반 모의 구현입니다. 활성 상태와 삭제가 즉시 반영되므로 실제 OpenStack의 비동기 상태 변화, 리전·서비스 버전 호환성, 네트워크 통신 가능성은 검증하지 못합니다.

처음 로컬 HTTP 시험은 샌드박스의 socket.bind 제한으로 실패했습니다. 루프백 포트 사용 권한으로 다시 실행하여 통과했으며, 시험 종료 후 서버 스레드와 포트를 정리했습니다.

## 재현 명령

README의 설치 명령으로 환경을 구성한 뒤 실행합니다.

```sh
uv run --frozen pytest -q
uv run --frozen ruff check .
uv run --frozen ruff format --check .
uv run --frozen mypy
uv build --offline
```

검증한 버전은 Python3.12.14, FastAPI0.142.2, openstacksdk4.20.0, keystoneauth1 5.17.0입니다. 전체 의존성은 uv.lock에 고정되어 있습니다. 실제 OpenStack 버전 표기2025.02에 대한 호환성은 실제 서비스 조회 후 확인해야 합니다.

## 실제 배포 환경 읽기 확인

2026-10-01에 환경준비 - OpenStack 세션의 기존 SSH 접속을 사용하여 내부 DevStack demo 프로젝트의 설정을 로컬 .env에 반영했습니다. 비밀 파일은 Git에서 제외하고 소유자 전용 권한으로 저장했습니다.

실제 Uvicorn과 SSH 터널을 실행하여 /health/live, /health/ready, /api/v1/servers?limit=1, /api/v1/images?limit=1, /api/v1/flavors?limit=1, /api/v1/networks?limit=1이 모두200을 반환하는 것을 확인했습니다. 잘못된 호출자 토큰은401로 차단됐습니다.

최초 ready는503이었으며, 준비 상태 읽기 제한을5초에서20초로 늘린 후 같은 읽기 검증이 모두 통과했습니다. 검증용 API와 터널은 종료했습니다. 실제 서버 생성·삭제·전원 제어는 실행하지 않았습니다. 위 표의 실제 환경 미실행 표시는 초기 구현 당시 기록이며, 이 절이 현재의 추가 검증 결과입니다.
